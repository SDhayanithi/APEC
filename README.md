# Adhiparasakthi Engineering College (APEC) - Student Login Portal

Official responsive **Student Login Portal** for **Adhiparasakthi Engineering College (APEC)**, Melmaruvathur.

Built using **Pure HTML5, Vanilla CSS3, and JavaScript (ES6)**. Designed with a modern, glassmorphic light theme tailored for mobile and desktop screens.

---

## 🚀 Live Demo & Deployment

- **Live GitHub Pages Website:** [https://sdhayanithi.github.io/APEC/](https://sdhayanithi.github.io/APEC/)
- **GitHub Repository:** [https://github.com/SDhayanithi/APEC](https://github.com/SDhayanithi/APEC)

---

## ✨ Features & Highlights

- 🎨 **Modern Glassmorphism UI**: Clean, light theme with curated HSL accent colors (`#655CF6` / `#8278FF`).
- 📱 **Fully Responsive**: Mobile optimized (320px, 375px, 390px, 430px, 768px, 1024px+).
- 👁️ **Password Eye Toggle**: Interactive show/hide password visibility icon button.
- ♿ **Accessibility & SEO**: Built with semantic HTML5 tags, ARIA attributes, keyboard accessibility, and meta tags.
